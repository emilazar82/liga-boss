# Trainerbank

Fußballmanager im Retro-Look, komplett in einer einzigen Datei (`index.html`). Läuft im Browser, Spielstände bleiben auf dem Gerät.

Spielen: https://emilazar82.github.io/trainerbank/

## Inhalt

- `index.html` – das ganze Spiel (Code, Grafiken und Sounds eingebettet)
- Alle Vereine und Spieler im Spiel sind erfunden.
- Eigene Namen, Kader und Wappen lassen sich im Spiel unter „Eigene Daten“ einlesen. Sie werden nur im Browser des Geräts gespeichert und gehören nicht in dieses Repository (siehe `.gitignore`).
